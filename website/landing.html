FAQ

Common questions

Is Markdown Explorer free?

Yes. The project is MIT licensed and the GitHub repository is public.

Does it work without internet?

Yes. Rendering and searching happen locally. The website download buttons use GitHub only to find the latest release files and public download totals.

What document formats can I preview locally?

In addition to Markdown (.md), Markdown Explorer supports local previews of DOCX, PDF, XLSX, PPTX, HTML, ODT, ODP, ODS, RTF, and TXT files directly inside your workspace with local caching.

What is the difference between Rust Tauri and Electron builds?

Rust Tauri uses the OS webview for compact downloads, fast startup, and low memory. Electron bundles Chromium for identical rendering and maximum compatibility across older OS versions and Linux distros.

Does Markdown Explorer collect any telemetry or user data?

No. Markdown Explorer is 100% private and offline-first with zero telemetry, no tracking scripts, and no remote file uploads.

Which desktop file should I download?

Windows users can choose the NSIS installer (`Setup *.exe`) for Start Menu integration or the portable `.exe` to run directly. Linux users can choose `.AppImage` or `.deb`. macOS users should choose `.dmg`, with `arm64` for Apple Silicon and `x64` for Intel.
