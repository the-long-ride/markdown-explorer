# Markdown Explorer — Complete Knowledge Base & LLM Guide

> **Markdown files are built for AI agents. Markdown Explorer makes them pleasant for humans.**
> A local-first, privacy-focused documentation viewer, editor, split reader, and knowledge workspace.
> Turns Markdown, MDX, and mixed-document folders into an interactive, searchable documentation desktop application, VS Code extension, Chromium browser extension, and web app.

---

## 1. Overview & Metadata

Markdown Explorer is an open-source (MIT licensed), local-first tool designed to inspect, navigate, edit, and explore Markdown repositories. It renders GitHub-Flavored Markdown (GFM), Mermaid diagrams, LaTeX math, interactive data tables, automatic data charts, local office/document conversions, code blocks, and rich media. It includes workspace search, two-pane split views, inline editing, read-only Git history, knowledge graph visualization, and source-anchored bookmarks.

All scanning, indexing, parsing, rendering, and diffing happen locally on the user's machine. Zero telemetry, zero analytics, and zero cloud uploads.

## 3. Architecture & Tech Stack

The project is structured as a high-performance **pnpm monorepo** with shared UI, modular runtime adapters, and an asynchronous message bus:

### Monorepo Workspaces
- `ui/`: Shared React 19 frontend compiled with Vite 8 and TypeScript 5.8. Contains the core Markdown parser, AST renderer, CodeMirror 6 editor, split view, search engine, Workspace Insights engine, theme system, and all UI components.
- `vscode/`: VS Code extension wrapper. Hosts the UI within an isolated VS Code Webview, bridges VS Code commands and file systems, provides `@the-long-ride/markdown-them` document conversions, and executes read-only Git commands.
- `electron/`: Electron 43 desktop application. Manages BrowserWindow lifecycle, native menus, tray icons, Windows registry / File Explorer context menus, local file watchers (`fs.watch`), and local `git` runner.
- `tauri/`: Tauri 2.x native desktop shell written in Rust 2021 (`edition = "2021"`, Rust 1.96+). Uses native Webview2 (Windows) / WebKit (macOS/Linux) with in-process Rust document conversion adapters (`office_oxide`, `calamine`, `pdf-extract`, `html2markdown`, `rtf-parser`, `quick-xml`, `zip`).
- `chromium-xtension/`: Chrome Manifest V3 extension packaging the UI with Chrome Extension Storage and Web Workers.
- `website-app/`: Vite application serving the GitHub Pages demo with virtual files and File System Access API bridges.

### Core Libraries & Subsystems
- **Custom Markdown AST Parser & Renderer**: High-performance streaming parser (`ui/src/markdown/parser.ts`) generating an Abstract Syntax Tree with deterministic heading anchors, source line mappings, inline formatting, frontmatter parsing (via `yaml`), Wiki-links, transclusion, and raw HTML sanitization.
- **CodeMirror 6 Editor**: `@codemirror/view`, `@codemirror/state`, `@codemirror/lang-markdown`, `@codemirror/language`, and `@lezer/highlight` for syntax-highlighted, low-latency in-app Markdown source editing without heavy frameworks like Monaco or TipTap.
- **Mermaid 11 & ZenUML**: `@mermaid-js/mermaid-zenuml` and `mermaid` 11.16+ providing vector SVG diagram rendering with custom theme-aware palettes, responsive sizing, and fullscreen zoom modal inspection.
- **KaTeX 0.16**: High-speed, offline LaTeX math rendering for inline `$...$` and display block `$$...$$` equations.
- **highlight.js 11**: Syntax highlighting covering 25+ programming languages and shell command blocks (`bash`, `pwsh`, `zsh`, `sh`, `cmd`) with line numbering and copy buttons.
- **Chart.js 4**: Interactive chart visualization engine supporting 9 distinct chart types generated automatically from Markdown, CSV, and TSV tables.
- **pdfmake 0.3**: Client-side hybrid PDF generation packaging selectable, searchable text alongside crisp vector SVGs and raster images without opening the OS print dialog.
- **Web Workers**: Dedicated offline background workers for Workspace Insights indexing, link checking, duplicate text shingles, and relationship scoring.

### Asynchronous IPC Message Contract
All platforms communicate with the shared UI using a strictly typed, bi-directional message protocol:
- **`WebviewMessage` (UI -> Host)**: Commands including `openFile`, `scanWorkspace`, `searchWorkspace`, `saveDocument`, `listRepositoryHistory`, `readRevisionFile`, `exportPdf`, etc.
- **`HostMessage` (Host -> UI)**: Events and responses including `workspaceScanned`, `fileContent`, `documentSaved`, `repositoryHistoryResult`, etc.

## 5. Comprehensive Feature Breakdown

### 5.1 Document Reading & Rich Media
- **GitHub Flavored Markdown (GFM)**: Full GFM specification support with tables, task lists (`- [x]`), strikethrough (`~~text~~`), footnotes (`[^1]`), auto-linked URLs, and blockquotes.
- **GitHub Alert Callouts**: Modern alert boxes with custom styling: `[!NOTE]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, and `[!CAUTION]`.
- **Mermaid Diagrams (Offline)**: Flowcharts, sequence diagrams, class diagrams, state diagrams, ER diagrams, Gantt charts, pie charts, git graphs, C4 diagrams, mindmaps, architecture diagrams, timelines, Sankey diagrams, block diagrams, XY charts, requirement diagrams, packet diagrams, and ZenUML.
  - Automatically themed to match the active Markdown Explorer theme and dark/light mode.
  - Gantt charts scroll horizontally to prevent unreadable label compression.
  - Diagrams can be opened in the Media Modal for smooth 50%–1000% pan/zoom, theme toggling, and copying/saving as PNG.
- **LaTeX Math (KaTeX)**: Renders inline math expressions `$...$` and multiline centered display blocks `$$...$$` with high typography fidelity.
- **Code Blocks & Terminal Commands**: Syntax highlighting for 25+ programming languages using highlight.js with line numbers, language labels, and one-click copy controls. Special support for terminal fences (`bash`, `pwsh`, `sh`, `zsh`, `cmd`).
- **Interactive HTML Sandboxes**: Embed executable HTML snippets inside sandboxed iframes.
- **Media Support**: Embedded local video, YouTube video embeds, responsive image rows that stay grouped across viewports, and fullscreen backdrop-blur media lightbox.

### 5.2 Local Markdown Editing & Conflict-Protected Save
- **Opt-in Feature**: Markdown editing starts disabled by default; toggle on in **Settings → Features → Markdown Editing**.
- **Three Editing Modes**:
  1. *Rendered*: High-fidelity view of the parsed Markdown with clickable links, diagrams, and math.
  2. *Inline Edit*: Edit specific document sections directly in place.
  3. *Plain Source*: Full-document source editing powered by CodeMirror 6 with syntax highlighting, line numbers, and a formatting toolbar (bold, italic, headings H1–H6, quotes, code, lists, tables, undo/redo).
- **Conflict-Protected Save (`Ctrl+S`)**:
  - Every open document tracks the exact revision token observed when loaded.
  - If a file is modified externally on disk, Markdown Explorer prevents silent overwrites and displays a conflict resolution dialog offering:
    - **Reload from Disk**: Discard local changes and load new disk contents.
    - **Compare in Diff**: Open a side-by-side diff comparing the disk version with your unsaved working copy.
    - **Keep Mine**: Explicitly overwrite disk contents with your local changes.
- **Unsaved Changes Guard**: Prevents accidental data loss when closing tabs, switching workspaces, or quitting the app with unsaved dirty buffers.

### 5.3 Two-Pane Split View
- **Side-by-Side Document Comparison**: Open two documents simultaneously with independent pane focus, active document, view mode (Rendered, Inline Edit, Plain Source, Revision, Diff), and scroll positions.
- **Pane-Owned Tabs**: Each pane maintains its own tab strip. Dragging a file from the sidebar or dropping it onto a pane activates and opens the document specifically in that pane.
- **Isolated Rerendering**: Scrolling or editing in one pane does not cause performance-degrading rerenders in the other pane. When both panes view the same document (one editing, one rendered), updates sync after a 150 ms debounce.
- **Clean Close Behavior**: Closing split view promotes the currently focused pane to the primary full-width view and preserves its tab strip.

### 5.4 Read-Only Local Git History & Diff Viewer
- **Zero-Mutation Guarantee**: Built exclusively for inspection. Markdown Explorer never executes `git checkout`, `commit`, `stage`, `merge`, `reset`, `rebase`, or `stash`. Commands are passed as structured argument arrays to the local `git` binary.
- **Repository Commit Graph**:
  - Continuous SVG lane graph visualizing branches, merge parents, commit SHAs, authors, dates, and current `HEAD`.
  - Paged at 50 commits per page with infinite scrolling and instant search by SHA, author, or commit message.
- **Whole-Workspace Historical Mode**:
  - Selecting **"View workspace at this commit"** projects the entire sidebar file tree to that exact past Git commit without altering your disk or Git branch.
  - Read historical documents, run workspace search across historical files, or return to current HEAD at any time (`Return to current HEAD` restores your live uncommitted working files and tabs).
- **Document-Scoped History**:
  - Follows file renames backwards through time.
  - Allows instant read-only viewing of historical snapshots.
- **Myers Source Diff & Rendered Diff**:
  - *Source Diff*: Dependency-free Myers line diff displaying exact Added, Removed, and Unchanged lines with syntax highlighting.
  - *Rendered Diff*: Fully renders both document versions as rich Markdown and highlights changed source-backed visual blocks (tables, math, callouts, diagrams).

### 5.5 Workspace Insights & Wiki Links
- **Six Analytical Auditing Views** (accessible via `Ctrl+Alt+I` or More Actions):
  1. **Gallery**: Visual grid indexing all referenced media (images, Mermaid diagrams, videos, audio, documents) with diagram thumbnail previews, category filters, and search.
  2. **Links**: Comprehensive workspace link audit surfacing broken links, missing targets, invalid anchors, outside-workspace files, dynamic references, ambiguous Wiki Links, and optional external HTTP status checks.
  3. **Lint**: Structural Markdown diagnostics detecting heading level skips (e.g. H1 to H3), duplicate headings, malformed YAML frontmatter, misaligned tables, and inconsistent list indents, with path-level and rule-level suppression.
  4. **Duplicates**: Analyzes document similarity using text shingles; detects exact duplicates, repeated passages, and near-duplicate files with a configurable similarity threshold (50%–100%).
  5. **Graph**: Interactive 2D knowledge network graph with backlink traversal, 1st and 2nd degree neighborhood highlighting, node search, and zoom.
  6. **Related**: Deterministic related document ranking powered by direct links, shared tags, shared headings, and keyword overlap with explainable signal breakdowns.
- **Wiki Links & Transclusion Engine**:
  - Full Wiki Link syntax support: `[[Note]]`, `[[Note#Heading]]`, `[[Note|Custom Label]]`, `[[#Anchor]]`, and relative paths `[[./Subfolder/Doc]]`.
  - Transclusion embeds: `![[Note]]` or `![[Note#Heading]]` renders target content inline with cycle detection and depth limit guards.

### 5.6 Data Tables & Interactive Charts
- **Interactive Tables**: Automatically transforms Markdown tables, CSV code blocks, and TSV code blocks into rich data grids.
- **Controls**: Multi-select column filtering, sortable columns, text wrap/unwrap, row count badges, and per-column visibility toggles.
- **9 Chart Types**: Automatically detect numeric columns and render interactive charts:
  1. *Bar Chart* (Vertical)
  2. *Horizontal Bar Chart*
  3. *Line Chart*
  4. *Area Chart*
  5. *Scatter Chart* (Multi-numeric X/Y point mapping)
  6. *Radar Chart*
  7. *Polar Area Chart*
  8. *Pie Chart*
  9. *Doughnut Chart*
- **Fullscreen Chart Modal Viewer**: Dedicated inspection modal offering 50%–1000% continuous pan/zoom, on-the-fly chart type switching, and direct PNG image copying/saving.

### 5.7 Converted Document Previews (Offline Office & PDF)
- **Local Conversion**: Opt-in feature (**Settings → Features → Read DOCX, PDF, Office, and text files**) allowing local viewing of non-Markdown files:
  - Formats: `DOC`, `DOCX`, `PDF`, `HTML`, `XLS`, `XLSX`, `XLM`, `PPTX`, `ODT`, `ODP`, `ODS`, `RTF`, `TXT`.
  - Tauri uses native in-process Rust crates (`office_oxide`, `calamine`, `pdf-extract`, `html2markdown`, etc.). Electron and VS Code use `@the-long-ride/markdown-them`.
  - Caches converted Markdown by file modification time and file size for instant repeat opens.
  - Displays a subtle quality notice indicator (`converted-preview`, `legacy-best-effort`).

### 5.8 Scope View Modal
- **Deep-Dive Without Losing Context**: Right-click any document link and select **"Open as scope"** to open the linked document in an isolated modal overlay.
- **10-Step History Stack**: Bounded history (`MAX_SCOPE_DEPTH=10`) with animated depth segment indicators and Back/Forward buttons.
- **Open File Button**: Dedicated header button (`OpenFileIcon`) navigates the main workspace to the previewed file and closes the modal.
- **Hardware Navigation**: Full support for keyboard (`Alt+Left`/`Alt+Right`, `BrowserBack`/`BrowserForward`, `Escape`) and mouse buttons 3/4.

### 5.9 All-in-One Export Center
- **Export Formats**:
  1. *Standalone HTML*: Fully self-contained HTML file with embedded styles, scripts, and media.
  2. *Static Website (ZIP)*: Multi-page static documentation website complete with interactive sidebar tree, search bar, table of contents, and theme toggle.
  3. *Client-Side Hybrid PDF*: Generates clean, searchable, selectable PDF documents via `pdfmake` without opening the OS print dialog. Captures complex diagrams and charts as vector SVGs or crisp images.
- **Scopes**: Export the Current document, Selected files (with multi-select search filter), a Folder, or the Entire workspace.
- **Layouts**: Minimal *Document-only* or full *Explorer Viewport Shell*. Zero external CDN dependencies.

### 5.10 Source-Anchored Bookmarks
- **Opt-in Setting**: **Settings → Features → Enable Bookmark feature** (`Ctrl+Shift+B` on Desktop, `Alt+Shift+B` on VS Code / Chromium / Web).
- **Rich Target Capture**: Select any text (multi-line, mixed formatting, code, punctuation, symbols like `$`, `@`, `&`) or right-click rendered LaTeX formulas, Mermaid diagrams, images, or links to bookmark the exact object.
- **Version-2 Source Anchors**: Preserves exact source range, occurrence index, context fingerprint, and object identity. Repeated occurrences (e.g. the 3rd instance of "Error") resolve accurately.
- **Graceful Drift Handling**: If a document is edited and high-confidence relocation fails, the bookmark displays **Target changed** instead of jumping to the wrong passage.
- **Verified Persistence**: Bookmark saves and renames use verified persistence with translated green success toasts or red error toasts. The Bookmarks sidebar supports search, sorting, workspace grouping, and batch deletion with checkboxes.

### 5.11 Workspace Navigation & Organization
- **Sidebar Cursor Mode (`Alt+Z`)**: Keyboard-first tree navigation. Use `Up`/`Down` arrows to navigate, `Enter` to open or expand/collapse folders, and `Esc` to exit.
- **Locate Current File (`Alt+Q`)**: Instantly reveals and highlights the currently active file inside the sidebar tree.
- **Hoisted Pinning**: Pin frequently used files and folders to the top of the sidebar. Items in deep subfolders are hoisted to the root of the file tree for fast access (up to 15 items).
- **Scope Focus**: Focus on a specific subfolder; filters both the sidebar and workspace search. Changing scope automatically reruns active search queries.
- **Content Tabs**: Multi-document tab strip with close options (`Close`, `Close Others`, `Close to Right`, `Close All`).
- **Reading Progress & Scroll Memory**: Persists exact scroll positions and collapsed heading states across sessions for up to 100 recent files per workspace.
- **Hardware Mouse Navigation**: Universal Logitech and mouse buttons 3/4 back/forward support across all views and modals with 40 ms event deduplication.

### 5.12 Search System
- **Three Search Scopes**:
  1. *Current File* (`F` on Desktop, `K` on VS Code/Web)
  2. *Current Workspace* (`Ctrl+F` on Desktop, `Ctrl+K` on VS Code/Web)
  3. *All Open Workspace Tabs* (`Ctrl+Shift+F` on Desktop, `Ctrl+Shift+K` on VS Code/Web)
- **Match Highlighting & Excerpts**: Results display contextual excerpts; clicking a result jumps directly to the exact line in the document.

### 5.13 Custom Theming & Typography
- **Theme Families**: Built-in themes include *Explorer Classic*, *Bento Grids*, *Default*, *Vercel*, *Tokyo Night*, and *Neon Voltage*.
- **Pet Theme Companions**: *K-Ink (App author's dog)*, *White Shiba*, *Cat*, *Hamster*, *Corgi*.
- **Theme Remix**: Build, duplicate, customize, import, and export themes. Tweak primary/accent colors, background images, densities, and panel spacing.
- **Typography Controls**: Independent font family, style, and weight bindings for 6 distinct roles:
  1. *App UI Font*
  2. *Body Text Font*
  3. *Heading Font*
  4. *Quote Font*
  5. *Code Font* (defaults to JetBrains Mono)
  6. *Mermaid Diagram Font* (changing re-renders visible Mermaid diagrams)
  Supports system-installed fonts or imported `.ttf`, `.otf`, `.woff`, `.woff2` files.

## 7. Power-User Tips & Tricks

### Navigation & Discovery
1. **Hands-Off-the-Mouse Reading**: Press `Alt+Z` to enter **Sidebar Cursor mode**. Use the Up/Down arrow keys to highlight files, hit `Enter` to open, or expand/collapse folders. Hit `Esc` or click anywhere to exit.
2. **Never Lose Your Place in Big Projects**: When reading a deeply nested document, press `Alt+Q` (Locate File). The sidebar instantly scrolls to and highlights the active file.
3. **Drill Down with Scope Focus**: Right-click any folder in the sidebar and choose **"Focus on this folder"**. The sidebar hides everything outside that folder, and all workspace searches automatically restrict their scope to that folder.
4. **Instant Link Inspection with Scope View**: Don't want to lose your reading position or open another tab just to check a reference? Right-click any Markdown link and select **"Open as scope"**. A modal overlay displays the target document with a 10-step history stack. If you decide to stay, click the **Open file** icon in the modal header.

### Editing & Split View
5. **Side-by-Side Editing & Preview**: Press the Split View button in the topbar or right-click a file in the sidebar and choose **"Open in Split View"**. Keep one pane in **Plain Source** editor mode and the other pane in **Rendered** mode. As you type, the rendered pane mirrors your changes after a debounced 150 ms interval.
6. **Drag & Drop Between Split Panes**: You can drag any file from the sidebar and drop it onto either the left or right split pane to open the file directly in that pane.
7. **Resolving External File Edits**: If an AI agent or external editor updates a file while you have it open in Markdown Explorer, the editor detects the revision mismatch on save and gives you an instant side-by-side Myers Diff to compare before deciding whether to reload or keep your edits.

### Visualizations, Tables & Media
8. **Transform Data Tables into Charts with Zero Code**: Paste a standard Markdown table or a CSV/TSV code fence with numeric columns. Markdown Explorer auto-detects the numbers and displays a chart toggle. Click to switch between Bar, Line, Pie, Area, or Scatter views without modifying your Markdown file.
9. **Zoom & Pan Complex Mermaid Diagrams**: Click any rendered Mermaid diagram or image to open it in the Media Modal. Use the mouse wheel to zoom (up to 1000%), click and drag to pan across large architecture diagrams, and click the **Theme Toggle** icon in the modal footer to test how your diagram looks in dark vs. light mode.
10. **Export High-Resolution Diagram PNGs**: In the Media Modal, click **"Save as image (.PNG)"** or **"Copy PNG"** to export crisp, transparent, high-DPI raster images for presentations or bug reports.
11. **Filter 1000+ Row Tables**: For large tables, click the column filter button to multi-select specific values, sort by ascending/descending order, or toggle column visibility.

### Bookmarking & Auditing
12. **Bookmark Exact Formulas and Diagrams**: You don't have to select raw text to bookmark an equation or diagram. Right-click any rendered KaTeX formula or Mermaid entrypoint node and select **"Add Bookmark"**. Markdown Explorer captures its exact source anchor, occurrence, and visual identity.
13. **Audit Your Repository with Workspace Insights**: Press `Ctrl+Alt+I` to launch Workspace Insights:
    - Switch to **Links** to immediately catch all broken internal links, missing image assets, and dead anchors before publishing docs.
    - Switch to **Duplicates** to identify repeated documentation sections or copy-pasted guides across your project.
    - Switch to **Graph** to visually inspect how your documentation notes connect to one another through links and Wiki Links.

### Theming & Aesthetics
14. **Personalize Your Reader with Theme Remix**: Open **Settings → Theme Style → Theme Remix**. Choose a base style (e.g. Bento Grids, Tokyo Night, or Default), select a pet companion, adjust content width and line height, and even add a custom backdrop image. Export your theme JSON to share with teammates.
15. **Per-Role Font Pairing**: You can assign a clean geometric sans font to your **Heading Font**, a readable serif to **Body Font**, and a monospace font (like JetBrains Mono or Fira Code) to **Code Font** in **Settings → Typography**.

## 8. Settings Catalog Reference

All settings can be configured via **Settings (`Ctrl+,` or `Ctrl+I`)**, persisted per platform, or exported/imported as JSON:

| Setting Key | Type | Default | Description |

## 9. AI Agent & LLM Integration Guidelines

Markdown Explorer is built to serve as the visual reading and editing companion for AI coding and documentation agents:

1. **Agent Memory & Knowledge Bases**:
   - Point Markdown Explorer at an agent's memory folder (e.g. `.agents/`, `docs/`, or Obsidian vaults).
   - Agents can write standard Markdown with Wiki Links (`[[Concept]]`), and Markdown Explorer will instantly resolve references, transclusions, and interactive graph connections.
2. **Rich Visual Output for Agents**:
   - When generating complex architectures, agents should emit Mermaid code fences (`flowchart`, `sequenceDiagram`, `erDiagram`, `c4Context`, `architecture-beta`).
   - For mathematical derivations, agents should emit KaTeX `$math$` and `$$math$$`.
   - For datasets, metrics, or benchmarks, agents should emit Markdown tables or CSV fences; Markdown Explorer automatically provides interactive sorting, filtering, and chart visualization.
3. **Structured Alert Blocks**:
   - Agents should format critical notices using GitHub alerts (`> [!NOTE]`, `> [!TIP]`, `> [!IMPORTANT]`, `> [!WARNING]`, `> [!CAUTION]`). Markdown Explorer renders these with distinctive, accessible callout boxes.
4. **Source Diffing and Review**:
   - When an agent generates new versions of documents, users can compare past Git commits or unsaved drafts using Markdown Explorer's Myers Source Diff or visual Rendered Diff.
5. **Source-Anchored Bookmarking for Prompts**:
   - Users can bookmark specific sections, diagrams, or tables inside agent-generated files. Because bookmarks store exact line ranges and context fingerprints, they survive document editing and provide precise references for follow-up prompts.

## 10. Installation & Setup

### VS Code & VSCodium
Install directly from the command line:
```bash
code --install-extension the-long-ride.vscode-extension-markdown-explorer
```
Or search for `Markdown Explorer in VS Code` on the [VS Code Marketplace](https://marketplace.visualstudio.com/items?itemName=the-long-ride.vscode-extension-markdown-explorer) or [Open VSX Registry](https://open-vsx.org/extension/the-long-ride/vscode-extension-markdown-explorer).

### Windows Desktop (NSIS & Portable)
- Download the latest installer `Markdown-Explorer-Setup-*.exe` or standalone portable executable from [GitHub Releases](https://github.com/the-long-ride/markdown-explorer/releases/latest).
- The installer automatically registers **"Open with Markdown Explorer"** and **"Open Folder in Markdown Explorer"** in the Windows File Explorer context menu.

### macOS Desktop (Apple Silicon arm64 & Intel x64)
- Download the `.dmg` asset matching your Mac architecture from [GitHub Releases](https://github.com/the-long-ride/markdown-explorer/releases/latest).
- Drag `Markdown Explorer.app` into your Applications folder.

### Linux Desktop (AppImage & DEB)
- Download the `.AppImage` (make executable with `chmod +x` and run) or `.deb` package from [GitHub Releases](https://github.com/the-long-ride/markdown-explorer/releases/latest).

### Chromium Browser Extension (Chrome, Edge, Brave)
1. Download the `chromium-extension-*.zip` release artifact and extract it into a permanent folder.
2. Navigate to `chrome://extensions` (or `edge://extensions` / `brave://extensions`).
3. Enable **Developer mode** in the top-right corner.
4. Click **Load unpacked** and select the extracted folder.
