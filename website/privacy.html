Markdown Explorer

Privacy Policy

Markdown Explorer is built as a local Markdown reader. This policy explains what the website, VS Code extension, and desktop app handle, what stays on your device, and which third-party services may receive normal request information.

Effective date: June 3, 2026 Last updated: June 3, 2026
Summary Data We Handle Third Parties Storage Your Choices Contact

Summary

Markdown Explorer does not upload your Markdown files to us. The VS Code extension and desktop app read folders that you choose, render Markdown locally, and use local preferences so the product can remember things like recent workspaces, tabs, language, and theme.

The public website does not use analytics or advertising cookies. It uses browser local storage for your selected site language and color theme.

Data We Handle

  • Website preferences: your browser may store a language and theme value in local storage.
  • Local app data: the extension and desktop app may store local settings, recent workspace paths, open tabs, search state, and similar product preferences on your device.
  • Markdown content: files you open are processed locally for rendering, searching, diagrams, math, media, tables, and charts. We do not operate a backend that receives those files.
  • Support content: if you open a public GitHub issue, pull request, or discussion, GitHub may display the information you choose to share.

Third-Party Services

Some services are used to host the project, deliver assets, or help users install the software. These services may receive normal technical information such as IP address, browser, device, and request metadata under their own policies.

  • GitHub Pages hosts this website and may log visitor IP addresses for security purposes.
  • GitHub Releases and the GitHub API provide public download files, release metadata, and download counts.
  • GitHub raw content serves product images and logo assets used on the website.
  • Google Fonts loads the Inter font used by the public website.
  • Visual Studio Marketplace and Open VSX handle extension listing, installation, and download flows.

Storage and Security

Local preferences are stored on your device by your browser, VS Code, or the desktop app. You control those files and can clear browser storage, VS Code extension state, or desktop application data from your own system.

No software can promise perfect security. Keep your operating system, browser, VS Code, and Markdown Explorer updated, and avoid opening untrusted files or links.

Your Choices

  • You can use the app offline for local rendering and search.
  • You can clear local website preferences from browser storage.
  • You can remove local app preferences by clearing the relevant VS Code or desktop app storage on your device.
  • You can choose what information to share publicly when using GitHub issues, pull requests, or discussions.

Children's Privacy

Markdown Explorer is a developer and documentation tool. It is not directed to children, and we do not knowingly collect personal information from children.

Changes

We may update this policy as the product, website, or third-party services change. The updated version will be posted on this page with a new last updated date.

Contact

For privacy questions, open an issue in the Markdown Explorer GitHub repository. Avoid posting private information in public issues.
