Questions

Common questions

Is Markdown Explorer free?

Yes. The project is MIT licensed and the GitHub repository is public.

Does it work without internet?

Yes. Rendering and searching happen locally. The website download buttons use GitHub only to find the latest release files.

Which desktop file should I download?

Windows users should choose `.exe`. Linux users can choose `.AppImage` or `.deb`. macOS users should choose `.dmg`, with `arm64` for Apple Silicon and `x64` for Intel.
