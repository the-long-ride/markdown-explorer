Questions

Common questions

Is Markdown Explorer free?

Yes. The project is MIT licensed and the GitHub repository is public.

Does it work without internet?

Yes. Rendering and searching happen locally. The website download buttons use GitHub only to find the latest release files and public download totals.

Can it preview DOCX, PDF, Office, web, and text files?

Yes. Turn on Read DOCX, PDF, Office, and text files in Settings. Conversion happens locally and is best-effort, so complex page layout, images, or styling can differ from the original file.

Which desktop file should I download?

Windows users can choose the NSIS installer (`Setup *.exe`) for Start Menu integration or the portable `.exe` to run directly. Linux users can choose `.AppImage` or `.deb`. macOS users should choose `.dmg`, with `arm64` for Apple Silicon and `x64` for Intel.

Extension Install Guide

Follow these steps to load the unpacked extension in any Chromium-based browser (Chrome, Brave, Edge, etc.):

  1. Download the extension zip file and extract its contents to a folder.
  2. Important: Move the extracted folder to a stable, permanent directory (such as your Documents folder). Do not leave it in your Downloads folder or delete it, as moving it later will break the installed extension.
  3. Open your browser and navigate to the extensions management page:
    • Chrome: chrome://extensions
    • Brave: brave://extensions
    • Edge: edge://extensions
  4. Turn on the Developer mode switch (usually found in the top-right corner).
  5. Click the Load unpacked button (usually in the top-left) and select the extracted extension folder.
