# UI Theming, CSS Architecture, and Style Contracts

## Purpose and boundaries

Defines how visual themes, design tokens, View Transitions, modular global stylesheets, and automated CSS/LOC contracts work across the React UI.

- **In scope**: `ui/src/styles/**` (90 stylesheets total: 3 root entry files, 6 in `tokens/`, and 81 in `global/`), `ui/src/styles/fonts.css`, `ui/src/styles/tokens.css`, `ui/src/styles/global.css`.
- **Out of scope**: Theme state normalization and Remix modal logic (`feature.workspace-tabs-and-settings`) and component-local `.css` files under `ui/src/components/`.

## Observable behavior

- **Theme modes**: `data-theme` on `<html>` supports `'auto'`, `'dark'`, and `'light'`; `'auto'` defaults to dark and switches to light under `@media (prefers-color-scheme: light)`.
- **Theme-matched text selection (`tokens-base-themes.css`)**: Global `::selection` uses `background: var(--selection-bg, color-mix(in srgb, var(--accent) 28%, var(--bg)))` and `color: var(--selection-fg, var(--tx))`, with `--selection-bg` / `--selection-fg` defined across `:root`, `[data-theme="dark"]`, `[data-theme="light"]`, and `@media (prefers-color-scheme: light) { [data-theme="auto"] }`. Runtime font overrides use `body.is-desktop`, `body.is-electron`, `body.is-tauri`, and `body.is-web` (`body.is-chrome-ext` was removed).
- **Theme-adaptive scrollbars, VS Code webview reset & grab targets (`tokens-app-shell.css`, `global-export-runtime-followup.css`)**: Scrollbar thumbs and tracks bind to `border-radius: var(--r-s, var(--r))` (razor-sharp in Cyberpunk/Raw Grid, rounded in rounded themes), preserve a thin 5px track, enforce `min-height: 40px; min-width: 40px;` grab targets, and brighten on `:hover` / `:active` with `@supports not selector(::-webkit-scrollbar)` Firefox fallback. Under `@supports selector(::-webkit-scrollbar)`, `html, body, *` (and `html[data-mdn-export="true"] .mdn-export-file-list`) explicitly reset `scrollbar-width: auto; scrollbar-color: auto;` so Chromium 121+ does not disable `::-webkit-scrollbar` styling when host environments (such as VS Code webview host CSS) inject non-`auto` `scrollbar-color` or `scrollbar-width`.
- **Theme presets (`data-theme-style`)**: `raw-grid` (Default), `default` (Explorer Classic), `bento` (Bento Grids), `vercel`, `tokyo-night`, `neon-voltage`, `cyberpunk` (zero-radius chamfered `clip-path: polygon(...)` cyberdeck geometry), and 2 pet themes (`pet-white-shiba` "Nika", `pet-k-ink` "K-Ink"; `pet-cat`, `pet-hamster`, `pet-corgi` were removed from `tokens-pet-themes.css`, `tokens-pet-auto-light.css`, and `global-theme-picker-styles.css`). In `global-theme-picker-styles.css`, portaled theme menus use `z-index: var(--z-modal-overlay) !important`, `.theme-style-option--cyberpunk .theme-style-option__swatch` renders a chamfered polygon swatch, and unselected Cyberpunk option labels run a periodic 3s `@keyframes cyberpunk-option-glitch-3s` preview (disabled under `prefers-reduced-motion: reduce`, with `will-change: transform, text-shadow` scoped only to `:hover` / `:focus-visible`).
- **Custom themes**: Up to `24` custom themes override 20 CSS color variables per scheme (`light`/`dark`), layout tokens (`density`, `radius`, `strokeWidth`, `contentPadding`, `sectionGap`), and optional background image variables (`--custom-theme-bg-*`) on `html[data-custom-theme-id] body::before`.
- **View Transitions (`global-view-transitions.css`)**: Uses top-to-bottom / bottom-to-top feathered linear-gradient masks (`vt-mask-sweep-down`, `vt-mask-sweep-up`) and `.theme-magic-overlay`; `circle(...)` clip-paths are explicitly forbidden.
- **Cyberpunk modular surfaces, checkboxes, tooltips & File History (`global-theme-cyberpunk-*.css`, `global-search-overlay.css`)**:
  - `global-theme-cyberpunk-modals.css` & `global-table-chart-viewer.css`: Orbiting neon tracer beam (`@property --cp-beam-angle` rotating a `conic-gradient` via `@keyframes cp-beam-orbit`) masked to the exact 6-sided cut-corner perimeter on `::after` with a subtle base cyber wireframe, applied across all application modals (`.modal`, `.settings-card`, `.export-center__card`, `.search-overlay-card`, `.scope-view__card`, `.mdn-chart-viewer__frame`, etc.), plus Export Center HUD header/footer cyber styling. Wrapping the chart canvas in `.mdn-chart-viewer__frame` (`flex: 1 1 0; min-width: 0; min-height: 0; overflow: hidden`) ensures the Cyberpunk neon outline matches the chart modal container.
  - `global-theme-cyberpunk-search.css` & `global-search-buttons.css`: Dual-rail 45° chamfered `.search-overlay-card`, cyan/rose accents, `mark.mdn-search-jump-mark` inline highlight and `.mdn-search-jump-target` block-level pulsing outline (`@keyframes mdn-search-jump-pulse`), and chamfered inner-shape checkboxes without checkmarks (paired with `.search-overlay-workspace__checkbox` / `.scope-focus-checkbox` in `global-search-overlay.css` rendering an inner 8x8px pip on `:checked` or 2px bar on `:indeterminate`).
  - `global-theme-cyberpunk-scope-view.css`: Dual-rail chamfered `.scope-view__card`, parallelogram `.scope-view__depth-segment` HUD depth ticks, and flat `.scope-view__toc.toc-panel` container styling.
  - `global-theme-cyberpunk-menus.css`: 6-sided chamfered `.mdn-link-context-menu` content right-click menus with dual-layer cyan/rose drop shadows (including `@media (prefers-color-scheme: light)` auto-light overrides for `[data-theme="auto"][data-theme-style="cyberpunk"]`), plus File History modal header fixes suppressing separator `::before` pseudo-elements, aligning segmented (`28x28px`), compare (`28px` height, disabled opacity `0.45`), and close (`28x28px`) buttons.
  - `global-theme-cyberpunk-surfaces.css`: Portal tooltip keyframes for edge-aligned tooltips (`[data-tooltip-align="left"]` glitch animation without `-50%` horizontal shift).
- **Document scroller containment, snapshot viewer flex layout & table styles (`global-content-layout.css`, `global-content-tabs-focus-search.css`, `global-split-document-view.css`, `global-scope-view.css`, `global-history-diff.css`, `global-theme-cyberpunk.css`, `global-markdown-foundation.css`, `global-switch-tooltip-diff.css`, `global-sections-table-core.css`, `global-table-view-controls.css`, `global-code-syntax.css`)**:
  - `.content__scroll`, `.split-document-pane__scroll`, and `.scope-view__scroll` enforce `overflow-y: auto; overflow-x: hidden;`; `.mdn-body` and block children enforce `min-width: 0; max-width: 100%;` with `.mdn-body .mermaid svg` clamping across all document views. `.scope-view` renders at `--z-modal` (`130`), `.media-modal.mdn-modal` at `--z-modal-popover` (`140`), `body > .mdn-link-context-menu` / `.mdn-filter-dropdown` at `calc(var(--z-modal-overlay) + 20)` (`170`), and `.mdn-action-notice` at `calc(var(--z-tooltip) - 1)` (`179`).
  - In `global-history-diff.css`, `.repository-snapshot-content__header` enforces `flex: 0 0 auto;`, `.repository-snapshot-content__empty` centers the 520px `.repository-snapshot-content__commit-card` when no snapshot file is open, and `.repository-snapshot-content__scroll` (including high-specificity `[data-theme-style]` and `:root[data-theme][data-theme-style]` selectors) enforces `flex: 1 1 0; min-height: 0; height: auto;` with `.repository-snapshot-content__body { width: 100%; max-width: none; }`. In `global-theme-cyberpunk.css`, transparent reading-pane backgrounds exclude `.content:not(.repository-snapshot-content)` so the commit snapshot overlay keeps its opaque `var(--bg)` surface and viewport-bounded scroll container for sticky headers and sticky bottom codeblock controls.
  - Wrapped table headers (`.mdn-table-wrap.is-wrapped .mdn-th-content`) use wrapping flex-row alignment keeping actions inline when space permits and dropping to 2 rows when narrowed; `.mdn-th` binds to `top: var(--mdn-sticky-top-offset, -1px)` and `.mdn-th-content` (rather than `.mdn-table th`) owns `overflow: hidden` so `.mdn-table-col-resizer` handles remain unclipped in both Wrap and Unwrap modes alongside the 26x26px `.mdn-table-reset-widths` button.
- **Settings, Shell, TOC, Terms, Raw Grid & Codeblock CSS updates**: `global-code-blocks.css` keeps `.mdn-codeblock-header` static (non-sticky) while pinning expanded `.mdn-codeblock[data-collapsed="false"] .mdn-codeblock-toggle-btn` (`bottom: var(--mdn-sticky-bottom-offset, 0px)`, mirrored in `global-theme-cyberpunk.css`); `global-content-layout.css` and `global-theme-raw-grid.css` move top breathing room from `.content__scroll` onto `:where(.content__scroll:not(.content__scroll--plain-edit):not(.content__scroll--html-preview)) > .mdn-body:not(.mdn-body--html-preview)` so `.mdn-body .toc-compact` (`padding: 0; top: 0; z-index: var(--z-toc-overlay, 70)` in `global-toc-panel.css`) pins flush at `y = 0` above `.mdn-th` / `.mdn-table-columns` / `.mdn-table-view-dropdown`, while `.toc-compact.is-open .toc-compact__toggle` zeroes bottom radii and attaches `.toc-compact__menu` flush at `top: calc(100% - var(--stroke-w))` with `border-radius: 0 0 var(--r-lg) var(--r-lg)`; `global-app-shell.css` makes `.state-screen--initial-loading` / `.state-screen--tab-loading` transparent so `[data-theme-style="raw-grid"]` grid backgrounds on `.app`, `.content`, `.tab-loading`, and `.splash` (`global-theme-raw-grid.css`) remain visible during loading; `global-terms-modal.css` qualifies `.settings-card.terms-card` and sets `white-space: nowrap` on `.terms-link`; `global-settings-features.css` and `global-settings-navigation.css` provide a fixed-header scrollable Features panel (`.settings-features-section__scroll`, `.settings-navigation__content--features`); `global-theme-picker-settings.css` adds `:disabled` / `:not(:disabled)` states on `.segmented-option`; `global-settings-typography.css` positions `.desktop-font-size-unit` inside the `72px` `.desktop-font-size-input` stepper; `global-shell-control-sizing.css` styles `.web-demo-nav__btn--github:has(.web-demo-nav__stars-badge)` and `.web-demo-nav__stars-badge`; `global-theme-cyberpunk*.css` dropped `.export-center__cards label` selectors.
- **Editor visual table cells & status bar hint (`global-document-sections-tables.css`, `global-markdown-editing.css`)**: `.cm-table-cell` sets `white-space: pre-wrap; vertical-align: top;` so multi-line cell breaks display naturally during visual table editing, while `.markdown-source-editor__table-hint` (`.tooltip-content-wrap`) lays out the inline-flex focused-cell shortcut hint and themed `.keycap-3d` caps inside `.markdown-source-editor__status`.
- **Static style & LOC contracts**: `tests/contracts/ui-style-contract.test.ts` prohibits JSX inline `style` props (`useDomStyles`), native HTML `title` attributes on non-`<iframe>` elements, `circle(...)` transitions, hardcoded `12px` editor fonts, horizontal body scrollbars, clipped `.mdn-table th` overflow, z-index inversions above Scope View, host-inherited `scrollbar-color` / `scrollbar-width` overrides when `::-webkit-scrollbar` is supported, and legacy insights tokens. `tests/contracts/source-loc.test.ts` enforces `.css <= 500` LOC (and `.ts/.tsx <= 400`, `.rs <= 350`, `.js <= 350`).

## Workflow

1. `ui/src/styles/fonts.css` loads bundled `Be Vietnam Pro` and `JetBrains Mono` `@font-face` rules (desktop/web).
2. `ui/src/styles/tokens.css` loads base, foundation, vivid, pet, auto-light, and app-shell CSS variables and z-index scale.
3. `ui/src/styles/global.css` imports 79 feature/theme `global-*.css` modules plus `TourGuideOverlay.css` (while `global-file-history-modal.css` and `global-history-diff.css` are imported on demand by History components).
4. `useAppStateEffects` syncs `data-theme`, `data-theme-style`, and custom theme CSS variables onto `document.documentElement`.

## Code map

- `ui/src/styles/fonts.css`, `tokens.css`, `global.css` — stylesheet entry layers.
- `ui/src/styles/tokens/{tokens-base-themes,tokens-style-foundation,tokens-style-vivid,tokens-pet-themes,tokens-pet-auto-light,tokens-app-shell}.css` — color, radius, shadow, chart, and shell token sets.
- `ui/src/styles/global/global-*.css` — modular styles for shell, sidebar, content, split view (`global-split-document-view.css`), scope view (`global-scope-view.css`), search overlay (`global-search-overlay.css`), tables (`global-sections-table-core.css`, `global-table-view-controls.css`, `global-table-alignment.css`, `global-table-chart-viewer.css`), editor, history (`global-file-history-modal.css`, `global-history-diff.css`), insights, settings, Mermaid diagram families (`global-mermaid-rendering.css`), and theme overrides (`global-theme-*.css`, including Cyberpunk `surfaces`/`modals`/`search`/`scope-view`/`menus` partials).

- Root attributes: `html[data-theme]`, `html[data-theme-style]`, `html[data-custom-theme-id]`, `html[data-table-align]`, `html[data-theme-transitioning]`.
