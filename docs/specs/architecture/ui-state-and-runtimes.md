# UI State, Contexts, and Platform Runtimes

## Purpose and boundaries

Defines the client-side React UI architecture of Markdown Explorer: how the app paints a theme-aware boot splash and bootstraps across four host runtimes (Electron desktop, Tauri desktop, VS Code webview, and Web), communicates with host processes via `PlatformBridge`, manages global application state in `AppStateProvider`, coordinates document/wiki navigation and Git history/snapshot contexts, resolves workspace and bookmark search jumps, and orchestrates keyboard shortcuts, layout effects, modals, and lazy-loaded rendering libraries.

- **In scope**: `ui/index.html`, `ui/src/main.tsx`, `ui/src/App.tsx`, `ui/src/AppView.tsx`, `ui/src/AppShell.tsx`, `ui/src/useAppLayoutEffects.ts`, `ui/src/useAppSearchEffects.ts`, `ui/src/platform/*`, `ui/src/contexts/*`, `ui/src/types/*`, `ui/src/constants/*`, `ui/src/hooks/*` (except `useDesktop*`), `ui/src/components/{Topbar,Tour,Modal,shared}/*`, `ui/src/lib/renderLibs.ts`, `ui/src/readingProgress/*`, `ui/src/utils/*`, `ui/scripts/*`, `ui/vite.config.ts`.
- **Out of scope**: Host runtime backends (`tauri/`, `electron/`, `vscode/`, `website-app/`), desktop tabs & settings UI (`feature.workspace-tabs-and-settings`), and Markdown/editor/insights/export engines.

## Observable behavior

- **Theme-aware boot splash & instant-paint bootstrap (`ui/index.html`, `ui/src/main.tsx`)**: `ui/index.html` defaults `<html data-theme="auto" data-theme-style="raw-grid">` and executes a synchronous inline `<head>` boot script that reads `localStorage` (`markdown-explorer-ui-state` or `markdown-explorer-web-state`), maps legacy style aliases (`pet-shiba-memes -> tokyo-night`, `night-city-2077 -> cyberpunk`, `pet-shiba -> pet-white-shiba`, fallback `raw-grid`), and applies `data-theme`, `data-theme-style`, and any active custom theme (`data-custom-theme-id` plus hex CSS variables `--bg`, `--bg-s`, `--tx`, `--tx2`, `--bd-s`, `--accent`) before first paint so `.splash` renders in the user's saved theme (including the 48px `raw-grid` background grid). `main.tsx` runs `detectBridge(win)` (`createVsCodeBridge()` for `acquireVsCodeApi`, `createElectronBridge()` for `__TAURI__`/`__TAURI_INTERNALS__` adding `body.is-desktop` + `body.is-tauri` or `electronAPI` adding `body.is-desktop` + `body.is-electron`, or `createWebBridge()` for `__webBus` adding `body.is-web`), invokes `syncBootThemeToDocument(bridge.getState<PersistedState>())`, mounts `<Suspense fallback={bootLoadingFallback}><AppShell /></Suspense>` (a fullscreen `.tab-loading--fullscreen` fallback), and fades `.splash` after `appShellPromise.finally(() => dismissSplash())`.
- **First-run gates, Guided Tour & File Drop (`ui/src/App.tsx`, `ui/src/useAppLayoutEffects.ts`, `ui/src/components/Tour/*`, `ui/src/hooks/useFileDropOpen.ts`)**: Desktop runtimes gate on `TERMS_ACCEPTED_STORAGE_KEY === 'true'` (`TermsModal`, using `useDialogKeyboard` for Enter-to-continue once checked), then `THEME_ONBOARDING_COMPLETE_STORAGE_KEY === 'true'` (`ThemeOnboardingModal`, suppressed while `updatePromptOpen` and supporting language, color mode, theme style, desktop view mode, and Escape/Enter shortcuts), then `USER_TOUR_COMPLETE_STORAGE_KEY` (`requestStartUserTour()`). `TourStage` supports `'home' | 'selection' | 'workspace'`: `buildTourSteps(language, runtime)` appends `'selection'`-stage `workspaceSelection` and `settings` steps on `'desktop' | 'tauri'`, whereas `'web'` runs `'workspace'`-stage steps and injects the virtual `TOUR_DEMO_WORKSPACE_PATH` demo workspace (handled locally in `AppStateContext` via `isTourDemoPath`) only when no real workspace is open; spotlight/card geometry is computed in `tourTargetPosition.ts` (`computeTourTargetCoords`, `areTourCoordsEqual`), which returns `null` when no candidate element has non-zero layout bounds (`rect.width > 0 && rect.height > 0`) so `0x0` rects are never spotlighted, while `TourGuideOverlay` also observes `document.body` via `MutationObserver` (`childList`, `subtree`, `class`/`style`/`hidden` attributes) and `ResizeObserver` to schedule `requestAnimationFrame` target re-measurement as lazy chunks and layout settle. `useFileDropOpen` snapshots `dataTransfer.files` and `dataTransfer.items` synchronously before any `await`, routes web directory handles (`getAsFileSystemHandle()`) to `openFolder`, non-text single file handles (outside `.md/.mdx/.markdown/.txt/.html/.htm/.csv/.tsv`) to `openFileHandle`, and text/multi-file drops to `openDroppedFiles` (filtering unreadable files in `App.tsx` and checking `webkitGetAsEntry()?.isDirectory` fallback), while desktop drops resolve paths via `getDroppedFilePath`. Update checks (`useUpdateCheck` with `delayMs: 800`, `useUpdateNotificationState`) are disabled when `isWeb` / `runtime === 'web'`.
- **Runtime-aware shell & revision-snapshot TOC (`ui/src/AppView.tsx`, `ui/src/components/Topbar/*`, `ui/src/contexts/RepositorySnapshotContext.tsx`, `ui/src/useAppLayoutEffects.ts`)**: Renders `DesktopTabBar` when `(isDesktop || isWeb) && settings.desktopViewMode === 'tabs'`, otherwise `Topbar` when a workspace is active, and keeps `WorkspaceSelection` visible during `tourStage === 'selection'` on non-VS Code runtimes. `RepositorySnapshotProvider` accepts `previewSettings` (`defaultHtmlPreview`, `defaultHtmlCodeBlockPreview`, `defaultCsvPreview`, `language`) and memoizes `activeRendered` (`renderMarkdownClientSide` for `.md`/`.mdx` snapshot files when `repositoryView.mode === 'revision'`) and `activeToc`. `AppView`, `Topbar`, and `useAppLayoutEffects` read `useRepositorySnapshot()` so revision mode enables the TOC toggle, mounts the right-side `TableOfContents` panel with `entries={displayedToc}`, `rootId="snapshot"`, and `documentKey="${oid}:${path}"`, and binds `tocResize` (`180`–`360px`) against `effectiveTocLength` (alongside `sidebarResize` at `min: 290, max: 800, mode: 'synchronized'`). `WebDemoNavActions` renders on `isWebRuntime()` with mode switch (`?mode=web` vs `?mode=test`), download/features/privacy/terms links (`resolveWebsitePageUrl`), and a GitHub star badge (`★ {starsCount}` via `useGitHubStars()`, cached for 1 hour in `mdn_github_stars_cache` with `mdn-github-stars-updated` broadcast and `visibilitychange` refresh).
- **Modals, Tooltips, Backdrops & Support Prompt (`ui/src/components/{Modal,shared}/*`, `ui/src/hooks/{useDialogKeyboard,useSupportPrompt}.ts`, `ui/src/utils/supportPromptStore.ts`)**: `ScopeViewModal` portals into `document.body` at `--z-modal`, yields capture-phase `Escape` when `#mediaModal`, `#mdn-chart-modal`, `.mdn-align-dropdown`, or `.mdn-filter-dropdown` are open, strips inline `onclick` on `a[data-mdn-target]`, resolves relative links against `current.file.fsPath`, and mounts `ScopeViewToc`. `MediaModal` and `TabContextMenu` also portal into `document.body` (`MediaModal` at `--z-modal-popover`); `MediaModal` uses `executeThemeTransition` on its theme toggle, memoizes `svgInnerHtml` so React 19 zoom/pan re-renders do not overwrite imperatively updated Mermaid SVGs, guards new-gallery index sync, and re-renders Mermaid diagrams via `renderMermaidToSvg` on `theme`, `themeStyle`, or `activeCustomThemeId` changes (with `mediaGallery.ts` reading `wrap.dataset.originalCode` or `.mermaid`'s `dataset.originalCode`). `DocumentConflictModal`, `SwitchWorkspaceModal`, `TermsModal`, `UnsavedChangesModal`, and `WorkspaceSelectionConfirmModal` share `useDialogKeyboard` for Escape/Enter handling. `SupportPromptModal` (`useSupportPrompt`, `supportPromptStore.ts`) displays live GitHub stars and tracks separate web-demo file-open/usage thresholds vs desktop usage thresholds. `HoverTooltipPortal` renders delayed (`320ms` / `60ms`) viewport-clamped tooltips for `[data-hover-tooltip]`, while `parseShortcutText.tsx` and `shortcuts.ts` (`ShortcutKeycaps.tsx`) parse bracketed, parenthesized, and bare modifier shortcut tokens—including localized modifiers (`Maj`, `Mayús`, `Entrée`, `Intro`) and arrow tokens (`←`, `→`, `←/→`) without swallowing trailing colons—into `.keycap-3d` `<kbd>` caps; `InteractiveBackground` and `CyberpunkMatrixBackdrop` (24fps matrix rain/telemetry canvas when `themeStyle === 'cyberpunk'`) pause on `document.hidden` and `prefers-reduced-motion: reduce`.
- **Workspace Search Jump & Bookmark Jump (`ui/src/useAppSearchEffects.ts`, `ui/src/utils/searchJump.ts`, `ui/src/utils/searchJumpDom.ts`, `ui/src/utils/searchJumpResolver.ts`)**: `useAppSearchEffects` resolves the active document across single or split panes (`activeDocumentFile`), normalizes path keys (`normalizePathKey`), calls `returnToHead()` when selecting a live workspace/cross-tab search result or non-`revision://` `'search-jump'` event while in revision mode, retries DOM scrolling up to 8 times (`100ms` interval), and runs a `2500ms` cached-render recovery effect (`CACHED_RENDER_RECOVERY_MS`) if a newer `renderVersion` replaces jump marks. `searchJump.ts` delegates source offset/line/table resolution to `searchJumpResolver.ts` (`resolveNormalizedSourceTarget` with CRLF/LF and UTF-8 byte/UTF-16 offset conversion, `lineNumber`/column disambiguation, `deriveMarkdownStrippedQuery`, `findEnclosingSourceElement` via `data-mdn-source-start`/`data-mdn-source-end`, and `findTableRowForSourceLine`) and DOM stream matching/highlighting to `searchJumpDom.ts` (`buildTextStream`, `findMatchesWithCandidates`, `wrapMatches`, `revealElementAncestors` expanding collapsed `.mdn-section`, `<details>`, collapsed/filtered `table.mdn-table` rows, preview-mode code blocks, and collapsed code blocks, plus `scrollToActiveElement` with 250ms/600ms drift-correction re-scrolls).
- **State hydration, defaults & shortcuts (`ui/src/contexts/*`, `ui/src/hooks/{useKeyboard,keyboardUtils}.ts`, `ui/src/utils/zipBuilder.ts`)**: `AppState` defaults `themeStyle` to `'raw-grid'` (labeled `'Default'`; `'default'` is `'Explorer Classic'`), `settings.tableColumnAlignment` to `'intelligent'` (synced to `documentElement.dataset.tableAlign` and `--mdn-table-default-align`), `settings.fileTabs` / `bookmarksEnabled` / `markdownEditingEnabled` to `true`, and `settings.historySidebarEnabled` to `false`. `normalizeThemeStyle` migrates legacy aliases to `'tokyo-night'`, `'cyberpunk'`, or `'pet-white-shiba'` and coerces unknown values to `'raw-grid'`, while `reduceSettingsUiAction` short-circuits no-op `SET_SIDEBAR_ACTIVE_TAB` and `SET_SIDEBAR_COLLAPSED` actions. `keyboardUtils.ts` (`resolveKeyboardAction`) respects `disabledKeybindings` and editor formatting/font-size chords (`formatCommandForChord`, `fontSizeActionForChord`), supports `reload-window`, `plain-edit-current-document`, and `open-files`, and suppresses `back`/`forward` on editable targets; `useKeyboard.ts` also exempts `.cm-table-cell` targets (`isTableCellTarget`) from global capture-phase `Alt+ArrowLeft` / `Alt+ArrowRight` browser and scope back/forward navigation, and `editorUiTranslations.ts` defines `tableCellHint` across all 9 supported languages; `normalizeKeybindingsForRuntime` remaps `Ctrl+Alt+E` / `Ctrl+Alt+Shift+E` on `vscode` and `web`, deletes `reloadWindow` on `web`, removes zoom shortcuts outside `'desktop' | 'tauri'`, and gates `toggleWorkspaceInsights`. `useAppStateEffects` runs desktop typography sync across `'desktop' | 'tauri' | 'vscode' | 'web'`, hydrates `PersistedState`, posts `ready` with `readyId`, handles VS Code `restorePersistedState` -> `stateHydrated`, filters workspace-scoped host messages via `acceptsWorkspaceHostMessage(msg)`, and clears `editorSessionStore` entries when closing content tabs in `AppStateContext`. `useResetOnChange(deps, reset)` (`ui/src/hooks/useResetOnChange.ts`) compares `deps` via `Object.is` against `useState(deps)` and runs `reset()` during render so dependent UI state clears in the same render without effect cascades triggering `"Maximum update depth exceeded"`. `zipBuilder.ts` builds stored UTF-8 ZIP archives with CRC-32 for browser downloads, and `ui/scripts/dev-electron.mjs` grants Windows AppContainer read/execute ACLs via `icacls` before spawning Electron in dev mode.
- **Navigation, History & Lazy Libs**: `NavigationContext` maintains per-scope (`default`, `focus`, `tabId`) back/forward stacks and resolves `mdn-wiki-navigate` events; `HistoryProvider` manages `HistoryClient` and `FileHistoryModal`; `renderLibs.ts` provides retryable lazy loaders (`getHighlightJs`, `getMermaid`, `getChart`, `getKatex`); `readingProgressStore.ts` debounces (`500ms`) scroll/heading state for up to 100 recent files per workspace.

## Workflow

1. `ui/index.html` applies saved theme/custom-theme tokens synchronously to `document.documentElement`; `main.tsx` runs `detectBridge()` -> `syncBootThemeToDocument()` -> `PlatformProvider` -> `Suspense(AppShell)` and dismisses `.splash` when `AppShell` resolves.
2. `AppStateProvider` hydrates persisted state and emits `ready`.
3. Host responds with `readyAck` (and `restorePersistedState` on VS Code).
4. `App` evaluates Terms -> Theme Onboarding -> User Tour gates.
5. User actions dispatch `AppAction` / post `WebviewMessage`; host responses update `AppState` via `appStateReducer`, while search/bookmark selections resolve and highlight targets via `useAppSearchEffects` and `searchJump.ts`.

## Known limitations and open questions

- `isDesktop` in `ui/src/App.tsx` checks `typeof window.electronAPI !== 'undefined'` (true for both Electron and Tauri's shim), while `state.appRuntime === 'tauri'` arrives asynchronously in `readyAck`.
- `AppView(props: any)` in `ui/src/AppView.tsx` uses untyped `any` props rather than a strict interface.
