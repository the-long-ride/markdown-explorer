# Markdown Rendering, Media Embeds, and Interactive Data Tables

## Purpose and boundaries

Transforms Markdown, CSV/TSV, JSON, HTML previews, and plain text into an interactive reading surface supporting GFM, frontmatter, KaTeX math, syntax-highlighted code blocks, Mermaid diagrams, relative media/workspace link resolution, and interactive data tables. Out of scope: source-buffer editing state and export job orchestration.

## Observable behavior

- **Markdown & internal link pipeline**: `ui/src/markdown/inline.ts` detects internal markdown links for relative `.md`, `.mdx`, and `.markdown` targets (case-insensitive, with optional `?query` or `#fragment`, excluding scheme-prefixed or `//` URLs) and emits `.mdn-link--internal` anchors. `contentUtils.ts` (`isWorkspaceNavigationHref`) treats any non-empty, non-`#`, non-scheme, non-`//` href as a workspace navigation target.
- **Document click & overlay handling**: `documentClickHandler.ts` uses the streamlined delegated click handler (legacy duplicate handler removed). `useDocumentOverlays.tsx` passes `doc.filePath` to `findScopeFile()` so context-menu scope actions resolve relative workspace links against the active document.
- **Welcome & manual surface**: `WelcomePage.tsx` defaults to the `'manual'` tab (ordered `'manual'`, `'features'`, `'shortcuts'`), enables `supportsEditor` for desktop, `vscode`, and `web` (`window.__webBus` / `appRuntime === 'web'`), and `WelcomeLaunchpad.tsx` dispatches `createVirtualWorkspace` over `window.__webBus`. `UserManualTab.tsx` provides localized AI-help prompt copy.
- **Interactive data tables & HTML preview**: Enhances Markdown and CSV/TSV tables with per-column alignment (`Left`, `Middle`, `Right`, `Intelligent` — keeping pure inference in `intelligentTableAlign.ts` and DOM table inspection `inferTableColumnAlignmentFromDom` in `tableAlignHandlers.ts`), column filtering (`.mdn-filter-dropdown` layered at `calc(var(--z-modal-overlay) + 20)` above modals), JS-managed sticky table column headers (`syncStickyTableHeaders` in `contentUtils.ts` offsetting `stickyTop` below any visible `.current-file-change-notice` and `.mdn-body .toc-compact` bar via `--mdn-sticky-top-offset`), edge-drag and keyboard (`ArrowLeft`/`ArrowRight`, `Shift` = `40px` else `16px`) column resizing in both Wrap and Unwrap modes (`attachTableColumnResizers` in `tableResizeStore.ts`, cleaning up active drags on `pointercancel` and window `blur`), `Enter`/`Space` keyboard activation on `.mdn-th-actions [role="button"]` (in both live tables via `tableResizeStore.ts` and portable documents via `portableInteractionController.ts`), and layout restoration via `Table.restoreTableLayout` (`tableEnhancement.ts`, `tableHandlers.ts`). Wrapped tables render flexible single- or two-row header actions (`.mdn-th-content` flex wrap keeping sort/align/filter buttons inline with short headers and wrapping cleanly when narrowed). A dedicated SVG-only Reset Column Widths icon button (`#${id}-reset-widths` / `Table.resetColumnWidths`, alongside typed 9-locale `rendererUi.sort` and `rendererUi.alignIntelligent` labels in `auditedUiTranslationsBase.ts` and `tableUiLabels.ts`, and delegated in `portableInteractionController.ts`) appears immediately left of the Wrap/Unwrap toggle whenever custom column widths are active. `htmlPreviewActions.ts` (`openHtmlPreviewInBrowser`) opens a Blob URL directly when `runtime === 'web'` and posts `openHtmlPreview` to the host bridge on other runtimes.
- **Diagrams, media, and overflow containment**: Renders Mermaid blocks with lazy/deferred enhancement, zoom/pan/export controls, and relative asset resolution through the active runtime bridge. Enforces zero horizontal scrollbar across document reading bodies (normal, converted Markdown, split-view panes via `.split-document-pane__scroll { overflow-y: auto; overflow-x: hidden; contain: layout paint; }`, and scope view) alongside `.mdn-body` block containment and Mermaid SVG clamping (`.mdn-body .mermaid svg`) across all document mounts.
