# Markdown Rendering, Media Embeds, and Interactive Data Tables

## Purpose and boundaries

Transforms Markdown, CSV/TSV, JSON, HTML previews, and plain text into an interactive reading surface supporting GFM, frontmatter, KaTeX math, syntax-highlighted code blocks, inline color swatches, Mermaid diagrams, relative media/workspace link resolution, and interactive data tables. Out of scope: source-buffer dirty-state orchestration (`feature.local-editing-and-split-view`) and export job orchestration (`feature.workspace-insights-and-export`).

## Observable behavior

- **Markdown, frontmatter & internal link pipeline**: `ui/src/markdown/inline.ts` detects internal markdown links for relative `.md`, `.mdx`, and `.markdown` targets (case-insensitive, with optional `?query` or `#fragment`, excluding scheme-prefixed or `//` URLs) and emits `.mdn-link--internal` anchors carrying `data-mdn-target`. `contentUtils.ts` (`isWorkspaceNavigationHref`) treats any non-empty, non-`#`, non-scheme, non-`//` href as a workspace navigation target. `frontmatter.ts` (`findFrontmatterSourceRange`) computes the exact character span of leading YAML frontmatter (`--- ... ---`), which `DocumentBody.tsx` and `useDocumentEditingSurface.tsx` attach via `data-mdn-source-start`/`data-mdn-source-end` on `.mdn-frontmatter` so `useInlineMarkdownEditing.ts` supports inline frontmatter editing alongside block/table/source editing (`InlineMarkdownEditor.tsx`, `InlineTableEditor.tsx`, `LinkInsertDialog.tsx`, `TableInsertDialog.tsx`, `MarkdownFormattingToolbar.tsx`, `MarkdownSourceEditor.tsx`, `useInlineEditorHistory.ts`). `MarkdownSourceEditor.tsx` and `InlineTableEditor.tsx` delegate formatting commands on focused `.cm-table-cell` elements through `formatFocusedTableCell`, and `MarkdownSourceEditor.tsx` shows a localized table-cell hint (`[data-testid="markdown-source-editor-table-hint"]`) rendered with 3D shortcut keycaps (`parseShortcutText(labels.tableCellHint)`) whenever a rendered table cell is focused. `markdown/utils.ts` (`renderButton`), `ContentTabItem.tsx`, `SplitPaneTabs.tsx`, `SplitPaneView.tsx`, `RandomTipCard.tsx`, `globalHandlers.ts`, and `htmlPreviewActions.ts` emit `aria-label` + `.tooltip-text` / `data-hover-tooltip` (`TooltipButton` with `portalTooltip`) without native `title` attributes to avoid duplicate browser tooltips.
- **Document root registry, click/overlay handling & snapshot support**: `activeDocumentRoot.ts` supports `DocumentRootId = 'main' | 'primary' | 'secondary' | 'snapshot'`, exposes `getActiveDocumentRootId()` and `subscribeDocumentRoots(listener)` (notifying listeners on root registration, unregistration, active root changes, and resets), and `useDocumentRootRegistration.ts` uses `useLayoutEffect` to register roots synchronously and restore the previous active root ID when an active root (such as `'snapshot'`) unmounts. `documentClickHandler.ts` matches `.mdn-body a[href], .mdn-body a[data-mdn-target]` and falls back to `link.dataset.mdnTarget` when no inline `onclick` attribute is present (allowing commit-snapshot views that strip inline `Nav.go` handlers to route relative/wiki links). `documentInteractionTypes.ts` and `useDocumentInteractions.ts` accept `persistReadingProgress?: boolean` (default `true`; when `false`, uses non-persisting `createHeadingSectionInteractions` instead of `createTrackedHeadingSections`, skips scroll-persistence handlers, and syncs sticky table headers on mount, scroll, and window `resize`). `useDocumentOverlays.tsx` passes `doc.filePath` to `findScopeFile()` for relative scope resolution and accepts `disableBookmarks?: boolean` and `disableScope?: boolean` so ephemeral views can suppress bookmark selection and scope-view modals/menu items. `Content.tsx` portals `.mdn-action-notice` to `document.body`.
- **Welcome & manual surface**: `WelcomePage.tsx` defaults to the `'manual'` tab (ordered `'manual'`, `'features'`, `'shortcuts'`), enables `supportsEditor` for desktop, `vscode`, and `web` (`window.__webBus` / `appRuntime === 'web'`), renders `WelcomeHero.tsx`, `WelcomeLaunchpad.tsx` (dispatching `createVirtualWorkspace` over `bridge.postMessage` or `window.__webBus`), and `WelcomeFeaturesGrid.tsx` with localized tip groups (`welcomeTipGroups.ts`, `welcomeTipsContent.ts`, `welcomeTipsExtended{,A,B,C}.ts`). `UserManualTab.tsx` (`buildAiHelpPrompt`) provides localized AI-help prompt copy.
- **Interactive data tables, color swatches & HTML preview**: Enhances Markdown and CSV/TSV tables with per-column alignment (`Left`, `Middle`, `Right`, `Intelligent` — keeping pure inference in `intelligentTableAlign.ts` and DOM table inspection `inferTableColumnAlignmentFromDom` in `tableAlignHandlers.ts`), column filtering (`tableFilterHandlers.ts`, `.mdn-filter-dropdown` layered at `calc(var(--z-modal-overlay) + 20)` above modals), JS-managed sticky table column headers (`syncStickyTableHeaders` in `contentUtils.ts` offsetting `stickyTop` below any visible `.current-file-change-notice` and `.mdn-body .toc-compact` / `.toc-compact__toggle` bar via `--mdn-sticky-top-offset` and `--mdn-sticky-bottom-offset`, resynced on section expand/collapse in `globalHandlers.ts` and code/table collapse in `tableHandlers.ts`), edge-drag and keyboard (`ArrowLeft`/`ArrowRight`, `Shift` = `40px` else `16px`) column resizing in both Wrap and Unwrap modes (`attachTableColumnResizers` in `tableResizeStore.ts`, cleaning up active drags on `pointercancel` and window `blur`), `Enter`/`Space` keyboard activation on `.mdn-th-actions [role="button"]` (in both live tables via `tableResizeStore.ts` and portable documents via `portableInteractionController.ts`), and layout restoration via `Table.restoreTableLayout` (`tableEnhancement.ts`, `tableHandlers.ts`). Wrapped tables render flexible single- or two-row header actions (`.mdn-th-content` flex wrap). A dedicated SVG-only Reset Column Widths icon button (`#${id}-reset-widths` / `Table.resetColumnWidths`, alongside typed 9-locale `rendererUi.sort` and `rendererUi.alignIntelligent` labels in `auditedUiTranslationsBase.ts` and `tableUiLabels.ts`, and delegated in `portableInteractionController.ts`) appears immediately left of the Wrap/Unwrap toggle whenever custom column widths are active. `tableChartViewer.ts` wraps the chart viewport in `.mdn-chart-viewer__frame`. `enhanceColorSwatches.ts` (invoked by `runContentEnhancements.ts`) wraps hex (`#RGB`, `#RGBA`, `#RRGGBB`, `#RRGGBBAA`) and functional CSS color literals (`rgb/rgba/hsl/hsla/oklch/oklab(...)`) inside `code`, `table td`, and `table th` with `.mdn-color-token` and `.mdn-color-swatch`. `htmlPreviewActions.ts` (`openHtmlPreviewInBrowser`) opens a Blob URL directly when `runtime === 'web'` and posts `openHtmlPreview` to the host bridge on other runtimes.
- **Diagrams, media, and overflow containment**: Renders Mermaid blocks with lazy/deferred enhancement, zoom/pan/export controls, and relative asset resolution through the active runtime bridge. `mermaidRerenderQueue.ts` (`isMermaidNodeHidden`) detects nodes hidden via `[hidden]`, inline or computed `display: none`, collapsed `.mdn-section` (`data-expanded !== 'true'`), or closed `<details>` (excluding `<summary>`). `mermaidRendering.ts`, `mermaidLazyRendering.ts`, and `scheduleContentEnhancements.ts` (`hasPendingContentEnhancements`) skip hidden Mermaid nodes (deferring cached SVG DOM injection until inside `runInMermaidRenderLane` while visible), `mermaidRerenderLifecycle.ts` invalidates hidden Mermaid nodes on theme changes instead of queueing them while hidden, and `contentEnhancementScheduler.ts` observes `['data-expanded', 'open', 'hidden']` attribute mutations so expanding a collapsed section or `<details>` automatically renders pending diagrams with the current theme. `mermaidRenderToSvg.ts` executes `mermaid.initialize`, off-screen host mounting, `mermaid.run`, `prepareMermaidSvg`, and `snapshotSvgHtml` inside `runInMermaidRenderLane` before removing the host so layout queries have live dimensions, and `mermaidSvgSnapshot.ts` (`snapshotSvgHtml`) preserves unclamped intrinsic/viewBox dimensions when in-document CSS clamps the rendered bounding rect. Enforces zero horizontal scrollbar across document reading bodies (normal, converted Markdown, split-view panes via `.split-document-pane__scroll { overflow-y: auto; overflow-x: hidden; contain: layout paint; }`, and scope view) alongside `.mdn-body` block containment and Mermaid SVG clamping (`.mdn-body .mermaid svg`).
