# Repository Specifications Index

Knowledge map for `markdown-explorer`, covering shared UI state/rendering, platform runtimes (`tauri`, `electron`, `vscode`, `website-app`), and build/verification workflows.

## Architecture

- [UI State, Contexts, and Platform Runtimes](architecture/ui-state-and-runtimes.md) (`architecture.ui-state-and-runtimes`): React UI bootstrap, theme-aware boot splash (`ui/index.html`, `main.tsx`), platform bridge detection, AppState reducer/effects, guided tour & file-drop routing, navigation/history/snapshot contexts, source-aware workspace search jump (`searchJump*.ts`), keyboard/layout orchestration, and shared UI primitives.
- [UI Theming, CSS Architecture, and Style Contracts](architecture/ui-theming-and-styles.md) (`architecture.ui-theming-and-styles`): Theme modes (auto/dark/light), built-in & pet theme styles, custom theme remixing, View Transitions, VS Code webview `::-webkit-scrollbar` reset (`tokens-app-shell.css`), snapshot viewer flex/sticky containment (`global-history-diff.css`, `global-theme-cyberpunk.css`), modular CSS layers, and static style/LOC contract enforcement.
- [Tauri Desktop Runtime Architecture](architecture/runtime-tauri.md) (`architecture.runtime-tauri`): Tauri v2 Rust host architecture (`v1.7.2`): bootstrap, window/menu setup, Electron-parity preload shim, async `spawn_blocking` command dispatcher, bounded LRU converter/search caches, coalesced filesystem watcher, local-file/youtube-proxy protocols, and signed updater.
- [Electron Desktop Runtime Architecture](architecture/runtime-electron.md) (`architecture.runtime-electron`): Electron `43.8.6` desktop host architecture: startup/single-instance, frameless window & security containment, preload IPC bridge, workspace/search/git/insights handlers, bounded 256-entry LRU caches, segment-filtered watching, and Windows in-app updater.
- [VS Code Extension Runtime Architecture](architecture/runtime-vscode.md) (`architecture.runtime-vscode`): VS Code extension host architecture (`v1.7.2`): esbuild packaging, commands (including `reloadWebview`), file watchers, CSP-hardened webview bridge, theme normalization, scanner/search/Git/fonts/conversion, Markdown parity, and pruned insights modules.
- [Web App & Website Runtime Architecture (Chromium Extension Retired)](architecture/runtime-chromium-and-web-demo.md) (`architecture.runtime-chromium-and-web-demo`): Browser-hosted Web App (`website-app/`, `appRuntime: 'web'`, `window.__webBus`, pre-paint theme boot splash, virtual/local/test workspaces), 11-stage Interactive Feature Demo Studio (`/features/`), and Raw Grid static marketing website (`website/`); Manifest V3 Chromium extension retired in v1.7.2.

## Features

- [Workspace Selection, Desktop Tabs, Settings, and Themes](features/workspace-tabs-and-settings.md) (`feature.workspace-tabs-and-settings`): Recent workspace switching, multi-tab desktop/web session state, revision-mode TOC toggles, settings modal/typography/shortcut persistence, boot theme sync & View Transitions, theme/accent presets, and embedded mini-games.
- [Sidebar Navigation, File Tree, Search, and Bookmarks](features/sidebar-search-bookmarks.md) (`feature.sidebar-search-bookmarks`): Memoized file tree explorer, reactive document & snapshot heading outline (`TableOfContents` with `subscribeDocumentRoots`), live and Git-revision workspace search jump (`SidebarSearch`, `sidebarSearchTree`), and bookmark management in the primary sidebar.
- [Markdown Rendering, Media Embeds, and Interactive Data Tables](features/markdown-rendering-and-tables.md) (`feature.markdown-rendering-and-tables`): Unified/Remark/Rehype markdown pipeline, inline frontmatter editing, color swatches, visibility-aware Mermaid lazy/theme rerendering & SVG snapshotting, document root registration (`'snapshot'`), interactive data tables with alignment/filtering/resizing/charts, and virtualized CSV/TSV previews.
- [Local Editing, Dirty State, and Split View](features/local-editing-and-split-view.md) (`feature.local-editing-and-split-view`): In-app source, inline, and CodeMirror visual-table editing (`tableCellEditing.ts`, `tableVisualPlugin.ts`, `tableSelection.ts`), LRU CodeMirror session caching, dirty-buffer tracking/save/conflict/close guards, and synchronized side-by-side split view.
- [Git History and Diff Viewer](features/git-history-and-diff.md) (`feature.git-history-and-diff`): Per-file and workspace Git commit history inspection, virtualized commit DAG, three-mode source/split/rendered diff rendering, and interactive read-only commit snapshot viewing (`RepositorySnapshotContent`, `snapshotLinkResolution.ts`, `snapshotSearchJump.ts`).
- [Workspace Insights, Knowledge Graph, and Export](features/workspace-insights-and-export.md) (`feature.workspace-insights-and-export`): Batched worker workspace analytics (16-file batches, 120ms snapshot throttling, 80-item candidate caps), link/tag graph/lint/duplicates/gallery insights with AI remediation prompts, and HTML/PDF/Static Website export pipelines.

## Workflows

- [Build, Versioning, and Verification](workflows/build-and-verification.md) (`workflow.build-and-verification`): Monorepo build orchestration (`pnpm-workspace.yaml` security overrides), version & README synchronization, multi-platform packaging scripts, VS Code debug tasks, and Vitest/Node/Rust verification workflows.
